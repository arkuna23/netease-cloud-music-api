# NCBL protocol reference

The NCBL wire format and desktop playback fields were studied from
`NeteaseCloudMusicApiEnhanced/api-enhanced`, revision
`19c7dad6db7d660954c7a615a686ff0acb030f91`, `util/ncbl.js` and
`module/scrobble_v1.js`. The Rust implementation uses OpenSSL primitives.
